# Java & Spring Boot Projects

A collection of Java and Spring Boot projects demonstrating backend application development, authentication, database integration, and web application functionality.

These projects were developed as part of my early Java and Spring Boot development work and provide examples of working with the Spring ecosystem.

## 🚀 Projects

### Registration

A registration and login application demonstrating user authentication and security using Spring Boot.

**Technologies:**

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* JSP
* HSQL
* Maven

### Add Bank Account

A Spring Boot application focused on bank account-related functionality and backend application logic.

### Wallet Search

A Spring Boot project demonstrating wallet-related search functionality and application logic.

## 🛠️ Technologies

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* Maven
* JSP
* HSQL
* HTML
* CSS

## ▶️ Running the Registration Project

### Prerequisites

* JDK 7 or later
* Maven 3 or later

### Run

```bash
mvn clean spring-boot:run
```
